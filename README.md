# Smart Security Website

Welcome to the Smart Security Website! This project is a responsive website designed to showcase home security services, helping visitors explore security solutions, learn about the company, and get in touch with the team.

## 🌍 Live Demo

Explore the live version of the website [here](https://ziyad-code-glitch.github.io/Smart-Security/).

## 📖 About This Project

Smart Security is a multi-page website designed to present home security services through a modern and user-friendly interface. The website provides information about the company, its services, team members, and pricing options.

The website includes:

* **Home**: An introductory landing page featuring the main security services, a call-to-action section, and promotional content.
* **About**: Information about the company, its background, and its mission.
* **Services**: An overview of the available security solutions, including home security systems, surveillance installation, CCTV footage, and alarm systems.
* **Team**: A dedicated page introducing the team and its members.
* **Pricing**: A page presenting pricing information for the available services.
* **Contact**: A page that allows visitors to find contact information and get in touch with the company.

## 🚀 Key Features

* **Multi-Page Website**: Separate pages for Home, About, Services, Team, Contact, and Pricing.
* **Responsive Design**: A layout designed to adapt to different screen sizes and devices.
* **Interactive Navigation**: A navigation menu with links to the website's main pages and a mobile navigation toggle.
* **Animated Hero Section**: An engaging landing section featuring introductory text and an animated image.
* **Service Showcase**: Dedicated content highlighting home security and surveillance solutions.
* **Call-to-Action Sections**: Prominent buttons encouraging visitors to explore services and contact the company.
* **Newsletter Section**: An interface allowing visitors to enter their email address to subscribe.
* **Icon Libraries**: Visual elements that improve navigation and interface presentation.

## 🛠️ Technologies Used

* **HTML5** for website structure and content.
* **CSS3** for styling, layouts, and animations.
* **JavaScript** for interactive website functionality.
* **Bootstrap** for responsive layouts and interface components.
* **Bootstrap Icons, Boxicons, and Remix Icon** for interface icons.
* **AOS (Animate On Scroll)** for scroll-based animations.
* **GLightbox** for lightbox functionality.
* **Swiper** for interactive sliders and carousels.
* **Google Fonts** for typography.
